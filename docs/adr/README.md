# Method ADRs

These ADRs record the **controller method**, not a product architecture. Product ADRs (schema, tenancy, stack) stay in product repos.

| ADR | Title | Status |
| --- | --- | --- |
| [0001](0001-cos-worker-reviewer.md) | CoS, worker, and reviewer are separate roles | Accepted |
| [0002](0002-different-family-review.md) | Review is a different model family, posted as COMMENT | Accepted |
| [0003](0003-worktrees-and-parallel-tracks.md) | Worktrees isolate tracks; parallel only when files do not overlap | Accepted |
| [0004](0004-three-gate-classes.md) | Repository, staging, and production gates stay separate | Accepted |
| [0005](0005-goal-prompts.md) | Goal prompts are the standing instruction | Accepted |
| [0006](0006-meta-repo.md) | A meta-repo is a map, not a product | Accepted |
| [0007](0007-watchdog-heartbeat.md) | A 10-minute heartbeat watches running tracks | Accepted |

Status is accepted as of 2026-08-13.
